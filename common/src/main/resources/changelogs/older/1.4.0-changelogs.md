## Version Release v1.4.0 MC-1.21.1

### Additions
- Many items have now been given tooltips such as banners, potions, discs, and more!
- Many item tooltips have been updated and tweaked to be better worded (a full list of these tooltip changes can be found at the bottom of this changelog)

### Changes
- All tooltips now appear in "Gold" font
- Black dye's tooltip has been updated for easier visibility
- Removed Snow Pig compatibility as no mods will be natively supported other than creations of my own to allow other developers freedom of their own works
...this does not apply to the Arts & Crafts paintbrush references natively supported by this mod as that was allowed with the permission of KekeCreations
- Removed Excessive Building compatibility, this will be handled on Excessive Building's end in the future when it is ported to ML
- Removed contributor capes, those have been moved to RunicLib

### Fixes
- Fixed an issue that caused many items to not be able to be tooltipped
- Fixed appledog compatibility
